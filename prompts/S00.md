# S00 Agent workspace and repository hygiene

Depends on: none. Branch: step/S00-<name>.

Goal: Give the agent a safe, reproducible workspace and a clean repository to work in.

## Prompt

```text
Follow AGENTS.md. Step S00, branch step/S00-hygiene. Repository: MasterDineth/Velocast (Android, Kotlin, Gradle).
Read AGENTS.md, docs/README.md and docs/findings.md (BLD-01, SEC-09, CQ-07, DOC-01, DOC-02) first.

Do the following:
1. Add a root .gitignore for Gradle, Android Studio, build output, local.properties, keystores, *.apk and *.aab. Run git rm -r --cached on anything already tracked that matches it. Do NOT rewrite history; the owner already did.
2. Delete magisk/mirror.sh and remove every legacy name (MirrorServerMain, mirror-server.apk, mirror.sh) from scripts and string constants.
3. Replace the compiled-in default host 192.168.31.109 (client Protocol.kt and any layout) with an empty default.
4. Rewrite README.md so each technical statement matches the code. Use the real constants (5 s I-frame interval, 250 ms idle repeat, 20 s server watchdog). Remove claims that are not implemented (VBR, zero B-frames, zero backpressure). Add a Status section stating the project is pre-release and not safe on shared networks.
5. Add LICENSE (Apache-2.0), SECURITY.md (private vulnerability reporting), CONTRIBUTING.md (build, test and format commands, branch naming step/Sxx-name), and .github/pull_request_template.md with a definition-of-done checklist.
6. Add .github/workflows/ci.yml: JDK 17, Gradle cache, ./gradlew assembleDebug lint on push and pull request.
7. Create docs/README.md that indexes the documents in docs/.

Constraints: no behaviour change in Kotlin code except removing the default host. Small commits with clear messages.
Definition of done: assembleDebug and lint pass locally; git ls-files shows no generated files; README claims verified against the code (list what you verified); open a pull request.
Finish with the summary format required by AGENTS.md.
```

## Acceptance criteria

- git ls-files lists no build/, .gradle/, .idea/ or local.properties entries.
- ./gradlew assembleDebug lint passes on a fresh clone and in CI.
- Every number in README (intervals, timeouts) matches the code constants.
- No reference to the old default IP, mirror.sh or MirrorServerMain remains.

## Owner checks

- Choose the licence (Apache-2.0 is recommended because it is compatible with reusing scrcpy code).
- Confirm the repository is under 5 MB after the purge.
