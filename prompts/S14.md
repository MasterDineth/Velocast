# S14 Host app UI

Depends on: S08, S09, S10, S12. Branch: step/S14-<name>.

Goal: A calm, guided Host app: first run, Prepare checklist, pairing helper, status and advanced settings.

## Prompt

```text
Follow AGENTS.md. Step S14, branch step/S14-host-ui. Work in :app-host using :designsystem and the ChecklistEngine and HostStatus from S08. Read docs/design-spec.md (host screens, copy rules).

1. Screens and navigation: First run (what this app does; warns that Prepare should be done while the screen still works), Prepare checklist hub (progress bar, ChecklistRow list, one Fix next item button), Pairing helper (numbered steps, Open Wireless debugging button, advances when pairing completes), Status home (Ready or Needs attention card, address, method, last session, battery and charging, toggles Start after reboot and Keep awake while charging), Advanced (launch method radio ADB, Shizuku, Root with Optional and Advanced labels and a security note for Root; paired viewers with Revoke; logs and diagnostics; Reset).
2. ViewModels expose immutable UI state from HostStatus; side effects through events; no logic in composables.
3. Notifications: the persistent keep-alive notification states (Ready, Streaming, Needs attention) and a high-importance alert when a checklist item regresses, each with an action that opens the right screen.
4. Copy: follow the copy rules; use 'old phone' and 'viewer'; keep ADB, Shizuku and Root terms inside Advanced.
5. Accessibility: TalkBack labels, 200 percent font, 360 dp width, contrast in both themes.
6. Remove the legacy HostMainActivity UI and its 2-second polling after the new screens work.
Tests: ViewModel tests, screenshot tests for every state, instrumentation smoke test using a fake SettingsReader.
Definition of done: :app-host:check passes; walkthrough and TalkBack notes in the PR; summary per AGENTS.md.
```

## Acceptance criteria

- A new user completes Prepare in under five minutes on a real phone.
- Each checklist item shows its reason and exactly one fix action.
- Revoke and Reset are confirmed with plain warnings.
- Screenshot and ViewModel tests are green; TalkBack pass done.

## Owner checks

- Time a first-time Prepare with someone who has not seen the app. Note every hesitation and feed it back.
