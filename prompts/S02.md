# S02 Protocol v2 module

Depends on: S01. Branch: step/S02-<name>.

Goal: One shared, versioned, tested wire protocol with typed messages and strict validation.

## Prompt

```text
Follow AGENTS.md. Step S02, branch step/S02-protocol. Work only in :protocol and docs/protocol.md.
Read docs/findings.md (CQ-02, SEC-05, FUN-02, PERF-08) and the audit report Section 11 summary in docs/architecture.md.

Build protocol v2 as a pure Kotlin/JVM library:
1. Framing (big-endian). Server to client frame header: type u8, flags u8 (KEYFRAME, CONFIG, RESET, ERROR), seq u16, length u32, ptsUs i64, captureUs i64 (24 bytes). Client to server control: type u8, pointer u8, seq u16, param i32, x f32, y f32 (16 bytes). Maximum payload 4 MiB.
2. Message types: HELLO, SERVER_HELLO, AUTH_PROOF, VIDEO, CONFIG, VIDEO_SIZE, STATUS, ERROR, CLIPBOARD, TOUCH, KEY, TEXT, CONFIG_STREAM, KEYFRAME_REQ, PAUSE, RESUME, ACTION (shade, rotate, display power, wake, back/home/recents), PING, PONG, BYE. Define every payload.
3. Handshake: HELLO carries magic "VLC2", version, feature bitmap, 16-byte client nonce. SERVER_HELLO carries version, capabilities, 16-byte server nonce, device info. AUTH_PROOF is an HMAC-SHA256 over the transcript (crypto itself is implemented in S06; here define the interface Authenticator and a test double).
4. ErrorCode enum matching docs/product-requirements.md error catalogue.
5. Validators: pointer id 0..31, key allow-list (BACK, HOME, APP_SWITCH, VOLUME_UP, VOLUME_DOWN, POWER, WAKEUP, ENTER, DEL, basic text keys), finite coordinates in [0,1], bitrate 1..40 Mbps, fps 15..120, scale 0.5..1.0. Violations throw ProtocolException with a code.
6. Readers and writers over InputStream/OutputStream with reusable buffers (no per-message allocation on the hot path) and strict length checks.
7. Tests: golden vectors per message, round-trips, property-based fuzzing (1,000,000 random inputs must only ever raise ProtocolException), bounded-memory test, and a test that parses the byte-table examples in docs/protocol.md.
8. Write docs/protocol.md with byte tables, state diagram of the handshake and the error codes.

Do not touch app code yet except to remove the two old Protocol.kt copies if trivial; otherwise leave a TODO.
Definition of done: ./gradlew :protocol:check passes; docs/protocol.md complete; summary per AGENTS.md.
```

## Acceptance criteria

- Every message type round-trips; golden vectors committed.
- Fuzzing with at least one million random inputs produces only ProtocolException, never another exception, hang or unbounded allocation.
- docs/protocol.md matches the code (tests parse the worked examples in the document).
- Module is pure JVM with no Android imports.

## Owner checks

- Skim docs/protocol.md; this is the contract both apps and every launcher depend on.
