# S10 Root launcher (optional)

Depends on: S08. Branch: step/S10-<name>.

Goal: Keep root as an optional, safer and supervised way to start the server and recover after boot.

## Prompt

```text
Follow AGENTS.md. Step S10, branch step/S10-root. Work in :launcher-root and :app-host. Read docs/findings.md (FUN-10, SEC-06, SEC-07, PERF-06).

1. Implement RootLauncher : ServerLauncher using a persistent root shell (a maintained library such as libsu, after you check and record its licence) instead of spawning su every time.
2. Start the server with setsid and app_process from the installed APK or the pushed jar, with the PAIRING_SECRET passed on stdin. Keep PID, lock file and logs under /data/adb/velocast with mode 0700 or 0600. Use a lock file with flock for single-instance, and identify processes by exact argv from /proc/<pid>/cmdline (never substring match, never kill an unverified PID).
3. Supervision: restart on crash with exponential back-off (cap 60 s), stop after N failures within a window and report why through the status model.
4. Boot: generate a Magisk service.d script that waits for boot completion, waits for the network, starts the server once and exits; no infinite loops in the script. Regenerate it when the Host app updates (resolve the APK path dynamically).
5. Status: no /proc scans and no 2-second polling. Query the server through the shared status channel.
6. UI wording hooks: expose a flag so the UI can label this launcher Optional and Advanced and show a security warning.
Tests: script generation tests (golden output), supervision logic with a fake clock, exact-argv matching tests.
Definition of done: :launcher-root:check passes; device test plan in the PR; summary per AGENTS.md.
```

## Acceptance criteria

- Server starts after boot on a rooted phone without opening the app; crash restarts with back-off.
- State lives in /data/adb/velocast (mode 0700) and nothing in /data/local/tmp.
- Process matching uses exact argv; no substring kill.

## Owner checks

- Test on the rooted old phone: reboot, wait for Wi-Fi, connect from the viewer. Kill the server and confirm it restarts.
