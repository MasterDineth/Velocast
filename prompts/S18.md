# S18 Optional extensions: audio, file recovery, extra codecs

Depends on: S17. Branch: step/S18-<name>.

Goal: Add features after the product is stable: audio, file and photo recovery, and screenshots or screen recording of the old phone.

## Prompt (choose one feature per run)

```text
Follow AGENTS.md. Step S18, branch step/S18-<feature>. Implement exactly one of: (a) audio forwarding, (b) file and photo recovery, (c) screen recording and full-resolution screenshots. Each behind a feature flag, off by default.

(a) Audio: capture playback audio on the old phone as the shell user on Android 11 and later using the approach scrcpy documents; encode with Opus; add an AUDIO message type to the protocol; add jitter handling and a latency cap; add a Settings toggle and a mute control in the toolbox; test with generated tone and lip-sync check.
(b) File recovery: using the ADB sync service (pull) list DCIM, Pictures, Download and Documents; show a selectable grid with thumbnails fetched lazily; copy selected files into a folder the user picks with the Storage Access Framework; show progress and resume on reconnect; never request broad storage permissions; verify checksums where possible.
(c) Recording and screenshots: save the stream (copy of the H.264 NAL units muxed to MP4 with the correct SPS/PPS and timestamps) and full-resolution screenshots from the decoder output (ImageReader); save through MediaStore with correct behaviour on API 26 to 36.

For the chosen feature: update the protocol docs and tests, add UI in the design system style, add tests (unit and instrumented), run the performance and security suites to show no regression, and document the feature in docs/user-guide.md.
Definition of done: feature complete behind its flag, tests and docs updated; summary per AGENTS.md.
```

## Acceptance criteria

- Features are disabled by default, documented and covered by tests.
- No regression in the performance and security tests.

## Owner checks

- Decide which of these is worth building first; for broken-phone owners file recovery is usually the most valuable.
