# S01 Restructure, toolchain and SDK 36

Depends on: S00. Branch: step/S01-<name>.

Goal: Move to a modular build with a version catalog, quality gates and API 36, with no behaviour change.

## Prompt

```text
Follow AGENTS.md. Step S01, branch step/S01-restructure. Goal: modular build, no behaviour change.
Read docs/architecture.md and docs/findings.md (BLD-02, BLD-04, BLD-05, CQ-10).

1. Add gradle/libs.versions.toml (version catalog) and move every dependency and plugin version into it. Use current stable AGP, Kotlin, Gradle wrapper and AndroidX. Verify each version exists before using it; record versions and licences in docs/dependencies.md. Pin a JDK 17 toolchain.
2. Create modules: :protocol (pure Kotlin/JVM), :server-core (Android library), :client-core (Android library), :launcher-adb, :launcher-shizuku, :launcher-root (Android libraries, empty for now), :designsystem (Android library with Compose enabled, empty theme file), :app-viewer (application id com.mastersoft.velocast), :app-host (application id com.mastersoft.velocast.host).
3. Move code: daemon classes to :server-core (keep package, mark TODO for S03), Host UI and DaemonController to :app-host, client classes to :app-viewer. Do not refactor logic.
4. Set compileSdk and targetSdk 36 for both apps. Keep minSdk 26 for the viewer and 30 for the host and server-core. Fix compile errors and behaviour changes that break existing flows; do not redesign any UI.
5. Add ktlint (or Spotless) and detekt with a baseline so existing code passes; make ./gradlew check run lint, format check, detekt and unit tests. Update CI to run check.
6. Write the module dependency rules in docs/architecture.md (protocol <- server-core, client-core; launchers depend on protocol only; apps depend on cores and designsystem) and add an automated check that fails the build if :protocol gains an Android dependency or a launcher depends on an app.

Constraints: no functional change; if a move forces an API change, list it in the PR.
Definition of done: all modules build; ./gradlew check is green; list the manual smoke test you performed or that the owner must perform; PR open.
Finish with the summary format required by AGENTS.md.
```

## Acceptance criteria

- All modules build; :protocol has no Android dependency (enforced by a check).
- ./gradlew check is green locally and in CI.
- Both apps install and behave exactly as before (manual smoke test listed in the PR).
- targetSdk is 36 in both apps; no deprecated Gradle features that fail in the next major Gradle release.

## Owner checks

- Install both apps on the old rooted phone and the new phone and run a normal session as a regression baseline.
