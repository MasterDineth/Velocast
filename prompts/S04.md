# S04 Client core: session engine, decoder and touch

Depends on: S02. Branch: step/S04-<name>.

Goal: A viewer engine that never freezes silently: it detects loss, sheds old frames, recovers, reconnects and reports its state.

## Prompt 4A: session engine

```text
Follow AGENTS.md. Step S04A, branch step/S04a-session. Work in :client-core using :protocol. Read docs/protocol.md and docs/findings.md (FUN-03, FUN-08, FUN-09, CQ-04).

1. Implement SessionEngine with states Idle, Discovering, Connecting, StartingServer, Handshaking, Streaming, Paused, Reconnecting, Failed (see docs/architecture.md). Expose an immutable SessionState through StateFlow. Inject a ServerLauncher interface (start and stop a server and return a ServerEndpoint) and a StreamTransport interface (connect, read frames, write controls) so the engine is testable without Android.
2. Liveness: heartbeats both ways every 2 s; socket read timeout 5 s; declare the link lost after 6 s of silence.
3. Reconnect: exponential back-off 1, 2, 4, 8 then 15 s (cap) for up to 10 minutes (configurable). Re-run only the steps needed: try the handshake again first; relaunch the server only if it no longer answers.
4. Typed SessionError (sealed class with ErrorCode, user-facing cause key, optional detail) for DEBUGGING_OFF, DIFFERENT_NETWORK, AUTH_EXPIRED, SERVER_START_FAILED, INJECTION_DENIED, SCREEN_OFF, LOCKED, VERSION_MISMATCH, LINK_LOST. Map ERROR frames from the server into these.
5. Pause and resume: on app background send PAUSE, release the surface; on foreground send RESUME and KEYFRAME_REQ.
6. Replace MirrorClient's single-use coroutine scope design: MirrorClient becomes one StreamTransport implementation with a reader coroutine and a writer coroutine and structured cancellation.
Tests with a fake clock and fake transport: all transitions, back-off timing, heartbeat loss, pause/resume, cancellation leaves no running coroutines.
Definition of done: ./gradlew :client-core:check passes; summary per AGENTS.md.
```

## Prompt 4B: decoder, queue and touch

```text
Follow AGENTS.md. Step S04B, branch step/S04b-decoder. Work in :client-core (and the viewer app only where wiring requires it). Read docs/findings.md (FUN-02, FUN-04, FUN-05, PERF-02, PERF-03, PERF-07, PERF-08).

1. VideoDecoder: switch to asynchronous MediaCodec callbacks with a small input queue and a dedicated render thread. Configure KEY_MAX_WIDTH and KEY_MAX_HEIGHT for adaptive playback and recreate the codec when a CONFIG frame carries a different size. Handle MediaCodec.CodecException using isRecoverable and isTransient: reset or recreate and request a keyframe; never leave the decoder silently failed.
2. Replace the suspending Channel with capacity 6 and BufferOverflow.DROP_OLDEST. On any dropped frame set waitForKeyframe, send KEYFRAME_REQ and skip non-key frames until a frame with the KEYFRAME flag arrives.
3. Add a buffer pool (ring of preallocated byte arrays) for frame payloads and reuse control-packet buffers; remove per-frame allocations.
4. Touch: reliable, ordered delivery for DOWN, UP and CANCEL; coalesce MOVE per pointer (latest wins); cancel all pointers on pause and disconnect; map coordinates using VIDEO_SIZE messages and the letterbox rectangle.
5. Metrics: per-frame stage timings (receive queue, decode, render) using captureUs and a clock-offset estimate from the ping exchange; expose them as a StateFlow plus a ring-buffer log for the diagnostics screen.
Tests: decoder tests with recorded H.264 resources including truncated and corrupted data; queue policy tests; touch coalescing and no-stuck-touch tests.
Definition of done: ./gradlew :client-core:check passes; a short note on measured behaviour after an induced one-second stall; summary per AGENTS.md.
```

## Acceptance criteria

- State machine tests cover every transition and the back-off timing with a fake clock.
- A one-second induced stall never grows latency; a dropped frame recovers within 500 ms.
- The decoder survives truncated and corrupted streams and CodecException without freezing.
- No stuck touches after pause, disconnect or queue overflow.

## Owner checks

- With two phones, switch Wi-Fi off for 5 s and on again: the viewer should reconnect by itself. Background and foreground the viewer: the stream resumes with a fresh keyframe.
