# S03 Server core: extraction, session guard and media pipeline

Depends on: S02. Branch: step/S03-<name>.

Goal: A launcher-independent server with an authenticated session guard, validated input, a resilient media pipeline and clean state restoration.

## Prompt 3A: extraction, session guard, validation

```text
Follow AGENTS.md. Step S03A, branch step/S03a-server-core. Work in :server-core using :protocol.
Read docs/protocol.md and docs/findings.md (SEC-01, SEC-03, SEC-05, SEC-06, CQ-04, CQ-06, CQ-07).

1. Create entry point com.mastersoft.velocast.server.Main. Arguments: --port N (0 = ephemeral), --bind IP|loopback, --state-dir PATH, --secret-from-stdin, --log-level. On start print one line "READY port=<p> nonce=<n>" and flush stdout.
2. Replace the accept loop with SessionGuard. The protocol v2 handshake must finish within 3 s before any other byte is processed. Count failures per remote address with exponential back-off. Only an authenticated peer may replace the active session. One session at a time. Use HMAC-SHA256 with the secret from stdin for now (S06 replaces it with the final scheme behind the Authenticator interface).
3. Add a ServerSession state machine (Handshaking, Active, Closing) with a single owner for every resource (codec, virtual display, injector, sockets) and structured shutdown. Remove unsynchronised flags and the 1.5 s join on the accept thread.
4. Validate all network input with the :protocol validators; a violation sends ERROR and closes the session.
5. Rewrite the touch state machine in InputInjector: no UP or MOVE for unknown pointers, cancel all pointers on teardown and PAUSE, reuse arrays instead of allocating per event.
6. Remove /data/local/tmp assumptions: state and logs live under --state-dir. Replace println and System.err with a small Logger (levels, ring buffer, optional file). Stop swallowing Throwable silently; log with the cause.
7. Delete the SurfaceControl fallback and every legacy name; throw UnsupportedPlatformException where the display bridge cannot work.
Tests (JUnit, fakes for sockets and injector sink): SessionGuard auth success and failure, replacement rules, timeouts and back-off; touch state machine properties; validators.
Definition of done: ./gradlew :server-core:check passes; the server still starts through the existing root launcher on a rooted device (state how you verified or list it as a manual check); summary per AGENTS.md.
```

## Prompt 3B: media pipeline

```text
Follow AGENTS.md. Step S03B, branch step/S03b-media. Work in :server-core. Read docs/findings.md (FUN-01, FUN-02, FUN-06, PERF-01, PERF-04, PERF-09).

1. Encoder: set KEY_BITRATE_MODE (default CBR; keep a constant and a benchmark switch for VBR), KEY_MAX_B_FRAMES = 0, KEY_PROFILE to constrained baseline when MediaCodecInfo reports support, KEY_PREPEND_HEADER_TO_SYNC_FRAMES. Keep low-latency and realtime priority keys. Report the chosen settings in a STATUS message.
2. Keyframes on demand: handle KEYFRAME_REQ with PARAMETER_KEY_REQUEST_SYNC_FRAME; also emit an IDR after RESUME, after a size change and after any dropped frame.
3. Send path: a bounded FrameQueue of 3 frames with latest-wins policy (drop the oldest non-keyframes and force an IDR). A separate writer thread for PONG, STATUS and ERROR with priority over video. Smaller SO_SNDBUF (configurable, default 64 KB) and TCP_NODELAY. The encoder thread must never block on the socket.
4. Rotation and size: detect display size or rotation changes (poll every 500 ms through VirtualDisplayBridge, or use an IWindowManager rotation watcher if you can make it reliable). On change: stop capture, rebuild virtual display and encoder at the new size, send VIDEO_SIZE then CONFIG then an IDR, update InputInjector dimensions atomically.
5. State restore: record rotation lock and display power at session start and restore on session end. Add a separate CleanUp process started with setsid that restores state if the server is killed.
6. Put a monotonic capture timestamp (captureUs) in every frame header.
7. Capability report in STATUS: rotation watcher, display power control, notification shade, wake. Report INJECTION_DENIED when input injection is refused.
Tests: FrameQueue policy tests, rotation state machine tests with a fake clock, an instrumentation test that records 5 s of encoder output and asserts first frame is IDR with SPS/PPS and that a keyframe request yields an IDR within two frames.
Definition of done: ./gradlew :server-core:check passes; measured evidence for queue depth under a simulated stall and for size-before-frame ordering after rotation; summary per AGENTS.md.
```

## Acceptance criteria

- No network input is processed before authentication (unit tests prove it).
- Send queue never exceeds three frames under a simulated one-second stall; keyframe follows any drop.
- After rotation, VIDEO_SIZE arrives before the first frame at the new size and touch maps correctly.
- State restore works after normal exit and after kill -9 of the server.
- No /data/local/tmp paths, println calls or silent catch Throwable remain.

## Owner checks

- On the rooted old phone, start the new server through the existing root path, connect, rotate three times, kill the server and confirm rotation lock and display state are restored.
