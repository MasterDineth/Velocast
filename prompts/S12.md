# S12 Design system module

Depends on: S01. Branch: step/S12-<name>.

Goal: A shared Compose design system so both apps look and behave like one product.

## Prompt

```text
Follow AGENTS.md. Step S12, branch step/S12-designsystem. Work in :designsystem. Read docs/design-spec.md in full.

1. Implement VeloCastTheme (Material 3): colour roles from the tokens in docs/design-spec.md for light and dark, optional dynamic colour toggle, Roboto typography scale (Headline 24/32, Title 20/28, Body 16/24, Label 12/16), shapes (8, 12, 20, 28 dp), a Spacing object on a 4 dp grid, motion tokens that respect the system reduce-motion setting. Add semantic colours Success, Warning, Info with on-colours.
2. Implement components with the states listed in docs/design-spec.md: StatusChip (Ready, NeedsAttention, Offline, Connecting; icon + text + colour), DeviceCard, StepIndicator, ChecklistRow (Done, NeedsAction, Optional; expandable), ProgressSteps with a progress ring, ErrorPanel (cause, one fix button, details, copy diagnostics), ToggleRow, ChoiceRow, EmptyState, DiagnosticsLog, PinPad (secure, excluded from screenshots), Hud, ToolboxSheet.
3. All user-visible text in string resources with translator comments; no concatenated sentences. Add a pseudo-locale (en-XA) test that renders every component without clipping.
4. Accessibility: contentDescription or visible label for every interactive element, 48 dp minimum touch targets, state descriptions (for example 'Ready' as part of the card's semantics), and no colour-only meaning.
5. Add a ComponentGallery composable (debug only) and previews for light, dark, 200 percent font scale and 360 dp width. Add screenshot tests with a maintained Compose screenshot-testing library (check its current status and licence first).
6. Document usage in docs/design-spec.md (component do and do not).
Definition of done: :designsystem:check passes including screenshot tests; gallery reviewed on a device or emulator; summary per AGENTS.md.
```

## Acceptance criteria

- Every component has previews and a screenshot test in four configurations.
- TalkBack labels and 48 dp targets verified by tests and a manual pass.
- No colour is hard-coded outside the theme file.

## Owner checks

- Review the component gallery screen on a phone and a tablet.
