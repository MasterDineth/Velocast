# Security Policy

## Pre-Release Notice

VeloCast is currently **pre-release** software and is **not safe on shared or untrusted networks**. Known security gaps (including unauthenticated/unencrypted TCP transport and root-privileged daemon execution) are tracked in [docs/findings.md](docs/findings.md) and are being addressed sequentially in [docs/steps.md](docs/steps.md).

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately via GitHub's **Security Advisories** ("Report a vulnerability" on the repository's **Security** tab) or by contacting the repository maintainer directly.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Affected module(s) and commit/branch if known.

We will acknowledge receipt and coordinate a fix before public disclosure.
